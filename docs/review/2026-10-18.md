clipboard/storage/privacy/paste/hotkey paths, installation scripts, related tests,
and screenshot capture/editing lifecycle. The project has no published GitHub
Releases at review time. The committed project uses GRDB 6, Carbon hotkeys and a
macOS 14 deployment target; the tests require an Xcode 26 SDK. Old v0.1/private
notes/HotKey library documentation is stale.

Confirmed issues:

- High / P0: clipboard titles and error descriptions (potential SQL values) logged.
- High / P0: unavailable biometric policy returns success; no session relocking.
- High / P0: concealed/transient pasteboards are not filtered.
- Medium / P0: retention leaves contentful FTS rows; failed image inserts leave files.
- Medium / P0: image deletion trusts database paths outside the application cache.
- High / P1: delayed synthetic paste is sent to whichever app has focus.
- Medium / P1: first install requires an existing app and personal signing identity.
- Medium / P1: fixed global shortcuts have no user conflict recovery UI.
- Medium / P1: a search in flight can publish during the next query's debounce.
- Low / P1: finished scrolling capture retains image buffers while its owner lives.

Scope limitation: this is an engineering/source review, not a claim of exhaustive
vulnerability discovery. No dedicated security-scan report was generated (the
skill's companion resources were unavailable). No existing user data was opened.

## Remaining release gates

- No Developer ID-signed/notarized distribution exists; real first install, upgrade,
  Gatekeeper and launch/rollback validation remain necessary. Installer process/signature
  commands are mocked in Python tests; concurrent installer invocations are not serialized.
- Touch ID/password UI, sleep/lock/fast-user-switch, AX multiwindow paste, hotkeys across
  Spaces, Screen Recording and language downloads require the manual matrix in RELEASING.md.
- Only the CI runner's native OS/architecture is exercised automatically. Minimum macOS 14,
  Intel and macOS 26 UI behavior still need devices. UI memory/FPS/large screenshots have
  no measured improvement claim; CJK search remains linear and in-flight SQL is not interrupted.
- Storage is plaintext, heuristic filtering is incomplete, and deletion is logical. Old
  diagnostic logs, backups/WAL/snapshots and same-user processes remain outside the UI lock.
- Current tracked text scan found no actual credential/private key or private absolute path;
  this is not a complete binary or Git-history secret scan. Existing panel-stripe.png has a
  personal path; screenshot artwork/branding rights need review and synthetic replacement
  captures. Existing binary images and history were not deleted or rewritten.
- Private vulnerability reporting must be enabled/verified by the maintainer. This review
  does not change repository visibility, security settings, tags, releases or main.

Recommended first binary version: **v0.4.0-alpha.1**, prerelease only after the documented
signing, data-compatibility, permission and native-device gates. Version/tag creation and
publication need maintainer approval. Current committed application version remains 0.3.0.
