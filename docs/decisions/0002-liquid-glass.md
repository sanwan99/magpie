# ADR-0002：液态玻璃作为独立面板材质

状态：采纳。用户明确要求在 Magpie 中实现液态玻璃。

## 决策

在浅色 / 深色 / 跟随系统与现有风格之外，增加“液态玻璃 / 毛玻璃”的独立材质设置，默认液态玻璃。遵循原型 §11 的中性色、原生透光背景、键盘交互和分层阴影；不更改布局或剪切板逻辑。

macOS 26+、Xcode 26+ 使用公开的 `NSGlassEffectView` 承载同一个 SwiftUI 内容视图。搜索控件使用 SwiftUI `glassEffect`。保持 macOS 14 部署目标；旧系统或旧工具链退回 `NSVisualEffectView` 并添加柔和边缘高光，不承诺原生折射。

材质切换不重新创建面板或视图模型。浅深色和装饰风格继续独立工作；降低普通风格的面板遮罩，避免挡住系统玻璃。系统“减少透明度”启用时停用液态玻璃，并保持面板整体不透明；原生玻璃的虚化由系统管理，原毛玻璃强度设置保留给兼容材质。
